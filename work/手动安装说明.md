# Unturned 指令自动补全 0.1.9 测试版

完全退出游戏。升级时先把原来的整个 `Modules/CommandAutocomplete` 文件夹移到游戏加载目录外备份。解压安装包后，将包内 `Modules` 下的整个 `CommandAutocomplete` 文件夹复制到游戏的 `Modules` 目录。回退时先移出新版模块，再放回原模块目录。

使用未启用 BattlEye 反作弊系统的方式启动游戏。服务器无需安装。

输入 `/give 6` 查看候选。光标在输入末尾且没有选中文字时，Tab 和 Shift+Tab 可切换候选。鼠标左键点选后只填入聊天框，回车按游戏原有规则发送。可以用鼠标滚轮和滚动条浏览候选，拖动标题栏移动面板，并用图钉锁定位置。

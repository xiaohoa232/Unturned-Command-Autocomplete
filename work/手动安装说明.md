# Unturned 指令自动补全本地测试版

完全退出游戏，将原来的整个 `Modules/CommandAutocomplete` 文件夹移到游戏加载目录外，再将解压后的 `Modules/CommandAutocomplete` 整个文件夹复制到游戏的 `Modules`。回退时先移出测试版，再放回原模块目录。使用未启用 BattlEye 的方式启动游戏，服务器无需安装。

输入 `/give 6` 查看候选。Tab 和 Shift+Tab 切换候选，鼠标左键点选只填入聊天框，回车按游戏原有规则发送。鼠标滚轮、滚动条、拖动和图钉照常使用。

建议实测首次打开聊天、中文输入法、点选、滚动和重开聊天。有大型工坊地图时，留意首次准备候选和搜索期间游戏是否流畅。

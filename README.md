# Unturned 指令自动补全

为 Unturned 聊天输入框增加原版指令和常用参数候选。输入名称、名称的一部分或编号，即可搜索物品、载具、在线玩家与地图地点，按 Tab 补全或循环切换，减少手动查编号和输入长指令的步骤。

这是独立制作的非官方客户端模组，服务器无需安装。补全只修改聊天框中的文字，Enter 仍按游戏原有规则发送或执行，模组不会自动执行指令或提供管理员权限。

> 0.1.2目前为测试版：已完成编译及74项离线检查，本版游戏内验收尚未完成。

## 主要功能

- **指令补全：**输入 `/` 或 `@` 开头的原版指令，显示可匹配的候选。
- **名称与编号搜索：**支持当前资源中已有的中文名、英文名、内部名称和编号，不区分英文大小写；中文搜索取决于资源是否提供相应翻译。
- **参数补全：**按指令识别物品、载具、玩家、地图地点等参数；选中后填入原版指令需要的值。
- **键盘切换：**Tab填入或切换下一项，Shift+Tab切换上一项；修改文字后重新搜索。
- **玩家名单更新：**尚未选择时，约每秒随在线玩家变化刷新；已开始切换时保留原列表，修改文字或重开聊天后使用最新名单。
- **可移动候选框：**默认在输入框正下方并左侧对齐，拖动标题栏调整位置，图钉可锁定或解锁。本次游戏中保留位置与锁定状态，重启后恢复默认。

资源名称与编号来自游戏当前已加载内容，不依赖一份固定的网上编号表。

## 手动安装与升级

1. 退出游戏，下载并完整解压[0.1.2测试版发布页](https://github.com/xiaohoa232/Unturned-Command-Autocomplete/releases/tag/v0.1.2)中的 `Unturned-指令自动补全-0.1.2.zip`。
2. 在Steam库中右键Unturned，选择“管理”→“浏览本地文件”，找到包含 `Unturned.exe` 与 `Unturned_Data` 的游戏目录。
3. 打开游戏目录下的 `Modules` 文件夹；不存在时新建。升级时，先将旧的整个 `CommandAutocomplete` 文件夹移到 `Modules` 外备份，避免混用版本。
4. 把解压包中 `Modules` 内的整个 `CommandAutocomplete` 文件夹复制进去。
5. 从Steam选择未启用BattlEye的启动方式进入游戏，打开聊天，输入 `/gi` 检查候选并按Tab。

安装完成后，游戏目录内应有：

```text
Modules/CommandAutocomplete/CommandAutocomplete.dll
Modules/CommandAutocomplete/CommandAutocomplete.module
```

安装不替换游戏程序、其他模组或存档。卸载时退出游戏，把整个 `CommandAutocomplete` 文件夹移到游戏 `Modules` 外即可；恢复时再将完整文件夹放回。

## 使用示例

| 输入与操作 | 效果 |
|---|---|
| 输入 `/gi`，按Tab | 补全为 `/Give`；指令名大小写以候选显示为准 |
| 输入 `/Give maple`，按Tab选择所需物品 | 将搜索词替换为该物品的有效编号 |
| 输入 `/Give 中文物品名` | 搜索已加载资源中提供该中文名的物品 |
| 输入 `/Vehicle 名称片段` | 搜索载具候选 |
| 输入 `/Kick 玩家名片段` | 搜索当前在线玩家，选中后填入Steam玩家编号 |
| 输入 `/Teleport 地点名片段` | 搜索当前地图正式命名的地点 |

指令名与第一个参数之间使用空格，后续参数依原版规则使用 `/` 分隔，例如 `/Give 玩家名/物品名/数量`。数量、经验、时间、坐标和自由文本由玩家自行填写。

在输入末尾使用补全。候选最多保留256项，每页最多显示8项；候选太多时，继续输入以缩小范围。

## 已知限制

- 暂不支持在指令中间按光标位置补全，也不支持鼠标点选候选。
- Shift+Tab可能与Steam叠加界面快捷键冲突；真实游戏中的反向切换仍待验收，可先使用Tab正向循环。
- 若资源没有中文翻译或英文名称已被汉化覆盖，模组不会生成缺失的名称，可尝试内部名称或编号。
- 已开始Tab切换后，离线玩家可能暂时保留在本轮列表中；修改文字或重开聊天可获取当前名单。
- 游戏更新可能改变接口，需要重新构建并复测；暂不承诺跨版本兼容。

## 从源码构建

需要已合法安装Unturned的Windows电脑。游戏依赖程序集从本机游戏目录读取，不随仓库或下载包分发。

在仓库根目录打开PowerShell，把下列示例中的游戏路径替换为实际位置：

```powershell
& '.\work\build.ps1' -GamePath 'C:\Program Files (x86)\Steam\steamapps\common\Unturned'
& '.\work\run-core-tests.ps1'
& '.\work\run-panel-tests.ps1'
```

构建脚本使用Windows自带的.NET Framework C#编译器。模组输出到 `outputs/CommandAutocomplete-0.1.2/Modules/CommandAutocomplete`，退出游戏后按上面的步骤复制安装。
